            下载设置

            音质 / 元数据 / 目录 / 列表上限

            无需选择：每首歌都自动下载当前登录账号可用的最高音质（无损/臻品母带优先）。加密文件（.mflac/.mgg）会在下载后自动解密，并写入完整元数据，产出可直接播放的成品文件。

            开启后元数据中同时保存原文与翻译歌词。

            除标题 / 歌手 / 专辑 / 封面 / 歌词外，再写入曲目号、碟号、发行日期、流派、语言、唱片公司、歌曲简介、作词 / 作曲 / 编曲 / 制作人等制作名单、榜单与风格标签、ReplayGain 音量信息（每首歌多 3 次请求）。

            在音频文件旁额外生成同名 .json，保存该歌曲 ID 对应的完整元数据（含歌词原文与翻译）。

            点「选择文件夹…」在飞牛内嵌文件夹选择器中点选一个文件夹：选择的同时即完成授权（trim.file.userAccess），下载目录与访问权限一步到位，无需再单独配置。

            ～ 毫秒

            每个任务之间随机延时，避免触发风控。

            首

            点「全选 / 反选 / 下载选中」时，最多按整张列表补全到这么多首后生效（默认 500，最大 20000）。列表比这个还大时只处理前若干首，避免动辄几千首的列表卡住页面。

            界面与显示

            主题配色 / 付费内容

            「跟随系统」随手机 / 电脑的深浅色模式自动切换；选完立即预览，点页面最下方的「保存设置」后长期生效。

            付费单曲 / 需单独购买的付费数字专辑：二选一 —— 在列表里置灰（不可勾选、不可下载），或直接从列表隐藏。已购买的内容不受影响，正常显示。

            消息推送

            飞牛统一推送服务（可选）

            飞牛「统一推送服务」地址，结尾不要带斜杠（如 http://192.168.1.29:818）。留空则不发推送，只记录「消息日志」。

            每次推送都会带上请求头 Authorization: Bearer <Token>。

            推送内容按所选类型排版（Markdown / HTML 的排版已优化）；标题固定为「QQ音乐下载器-事件类型」，单条内容最长 5000 字符，超长自动截断。

            每累积 首汇总推一次
            创建任务时一次性汇总推一次
            每累积 首汇总推一次
            每累积 条汇总推一次

            按「数量阈值」聚合推送：填 1 = 每条明细即时推送，填 10 = 每 10 条明细汇总成一条（含详细信息）。一批任务全部结束（成功/失败都算）后，还会额外推一条「任务完成」通知，注明成功/失败数量与失败原因。

            首页板块

            显示开关 / 每块最多显示多少

            首页「为你推荐」里除原有四块外，还有下面这些板块（默认每块 30 条）。取消勾选即隐藏该板块的入口卡片与列表；数量只决定「最多显示多少」，服务器给多少就显示多少。

            个推荐歌单 首新歌
            首猜你喜欢 首每日推荐

            首页四个入口各自最多显示多少（默认 20 个歌单 / 30 首新歌 / 30 首猜你喜欢 / 50 首每日推荐）。这里只设上限，下限由 QQ音乐服务器决定：服务器只推了 10 首就显示 10 首，填得再大也不会凭空变多。
